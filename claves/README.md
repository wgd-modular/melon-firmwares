# Claves

A simple claves voice that blends a sine and a triangle wave. Its pitch
follows 1V/oct on the CV input.

## Controls

| Control | Function |
|---|---|
| **POT1** | Decay |
| **POT2** | Wave, sine to triangle |
| **POT3** | Pitch (shared with CV, 1V/oct) |
| **IN1** | Trigger |
| **OUT** | Audio output |
| **Button** | Plays a note |

## LED

The LED lights up for as long as a note rings. Its colour follows the pitch,
from green for low notes to red for high ones.
