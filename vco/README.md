# VCO

An oscillator with six waveforms, with anti-aliasing on the ones that have
hard edges. It plays all the time, there is no envelope.

## Controls

| Control | Function |
|---|---|
| **POT1** | Waveform: sine, triangle, square, saw, FM 4× and FM 2×, left to right |
| **POT2** | Coarse tune |
| **POT3** | Pitch (shared with CV, 1V/oct) |
| **OUT** | Audio output |
| **Button** | Octave up, steps through 0, +1, +2 and +3 octaves |

## LED

The LED shows the waveform:

| Colour | Waveform |
|---|---|
| $\color{#0080FF}{\text{██}}$ **Blue** | Sine |
| $\color{#00FF80}{\text{██}}$ **Mint** | Triangle |
| $\color{#FF2000}{\text{██}}$ **Red** | Square |
| $\color{#FF8000}{\text{██}}$ **Amber** | Saw |
| $\color{#CC00FF}{\text{██}}$ **Purple** | FM 4× |
| $\color{#FF00AA}{\text{██}}$ **Pink** | FM 2× |
